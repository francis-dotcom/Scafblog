## 📚 Complete Curriculum

### 🎓 **Phase 1: Foundations** (Weeks 1-8)

#### Module 0: AI Security Fundamentals

Your crash course in thinking like an attacker. Threat modeling, attack surfaces, risk assessment, and setting up your offensive security lab.

#### Module 1: Adversarial Machine Learning

Master the core attack techniques: FGSM, PGD, Carlini-Wagner, model poisoning, extraction attacks, privacy leakage. You'll break 20+ models.

**Milestone:** Launch successful adversarial attack with 90%+ evasion rate

---

### ⚔️ **Phase 2: Offensive Security** (Weeks 9-16)

#### Module 2: Red Team Operations

Full red team methodology for AI systems. Reconnaissance, exploitation, privilege escalation, persistence. You'll think like a professional pentester.

#### Module 3: Advanced Attack Techniques

Backdoor attacks, trojan models, prompt injection, jailbreaking, multi-stage exploits. The sophisticated attacks that make headlines.

**Milestone:** Complete CTF challenge - compromise vulnerable AI system

---

### 🛡️ **Phase 3: Defensive Security** (Weeks 17-24)

#### Module 4: Defense Mechanisms

Now you learn to defend. Adversarial training, input validation, certified defenses, anomaly detection, monitoring and incident response.

#### Module 5: Secure ML Engineering

Build security into the ML development lifecycle. Privacy-preserving ML, differential privacy, federated learning, secure deployment pipelines.

**Milestone:** Build and deploy secure ML API with full security stack

---

### 🎖️ **Phase 4: Professional Practice** (Weeks 25-32)

#### Module 6: Security Auditing

Learn to conduct professional security assessments. Audit methodology, vulnerability documentation, risk scoring, remediation recommendations, client communication.

#### Module 7: Capstone Project

Your final challenge: Conduct a complete security audit of a real-world AI system (anonymized client). Full threat model, penetration testing, professional report, executive presentation.

**Milestone:** Deliver professional security audit report

## ❓ Frequently Asked Questions

### About Prerequisites

**Do I need a background in security?**  
No. We assume zero security knowledge. But you must be a competent software engineer with production experience.

**What if I'm strong in Python but weak in ML?**  
You need basic ML understanding (what is training, inference, loss functions). We'll teach you the security parts, but won't teach ML from scratch.

**Can I apply if I'm still in school?**  
Yes, if you meet all technical prerequisites and can commit 25-35 hours/week consistently.

### About Time Commitment

**Can I do this part-time while working full-time?**  
Only if you have extremely flexible hours. Most successful students work part-time (20 hrs/week max) or are between jobs.

**What if I miss a live session?**  
Sessions are recorded, but attendance is strongly encouraged. Missing 3+ sessions puts you on academic warning.

**What if I fall behind?**  
You get 2 "late week" passes. After that, falling behind risks removal. We don't slow the cohort for individuals.

### About Career Support

**Do you guarantee job placement?**  
No. We provide support, connections, and coaching, but **your portfolio is your placement tool.** If you do the work, you'll be highly competitive.

**What's the typical time to land a role?**  
Most graduates land offers within 2-3 months of graduation. Some have offers before graduating.

**Will this help me with traditional security roles too?**  
Absolutely. The skills transfer directly to web pentesting, cloud security, and general security engineering.

### About Costs

**Are there scholarships available?**  
Limited need-based scholarships available. Decisions made during application process.

**What if I need to drop out?**  
Full refund if you withdraw in first 2 weeks. No refund after. If we remove you for performance, no refund.

**Can I defer to a later cohort?**  
Yes, with 30 days notice before start date. One deferral allowed.

### About Technical Details

**What if my equipment doesn't meet requirements?**  
You cannot participate. Requirements are non-negotiable. Cloud alternatives discussed in Equipment Requirements.

**Do you provide access to commercial tools?**  
Yes. Burp Suite Pro, vulnerability scanners, and specialized ML security tools included.

**What operating system do I need?**  
Ubuntu 22.04 LTS (native or WSL2). macOS acceptable for some modules but Linux required for labs.
